name: script-format
description: Writing the script so the client, the manager, the editor and the videographer all read it the same way

---

The script is written as numbered beats. Every beat has:
- **Time**: its range in the video ("0:00–0:02"). The ranges add up to the target length.
- **Title**: 2–4 words naming the beat ("Hook", "The dough", "First customer").
- **What we see**: the shot or shots, concrete enough to film ("Close-up: the alarm clock flips to 3:58").
- **What's said**: the exact line, labelled VO for voice-over or the person's name; empty when nothing is said.
- **On screen**: the words that appear, exactly as they'll be written; empty when none.

Also:
- Write in the language of the video for what's said and shown on screen; everything else in English.
- The client reads this to approve: no jargon, no technical camera talk in "What we see" beyond what helps them picture it.
- Keep camera details (lenses, movement, takes) for the shoot plan, not the beats.
- The plain-text script repeats the same beats in the same order, so anyone can read it without the app.
